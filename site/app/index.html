갤럭시 · 안드로이드

갤럭시 APK 받기FingerError.apk · 폰에서 누르세요
  1. 파일 받기위 초록 버튼을 누르세요. "파일을 다운로드할까요?"가 나오면 다운로드.
  2. 파일 열기다운로드가 끝나면 아래에 뜨는 열기를 누르세요.

    놓쳤다면 내 파일 → 다운로드에서 FingerError.apk를 누르면 돼요.

  3. 출처 허용"보안상 이 출처의 앱을 설치할 수 없어요"가 나오면 설정 → 이 출처 허용을 켜고 뒤로 가세요.
  4. 설치설치를 누르세요.

    "Play 프로텍트" 창이 뜨면 자세히 → 무시하고 설치. 플레이스토어 밖에서 받은 앱이라 뜨는 기본 안내예요.

  5. 앱 열기핑거에러 앱을 열고 키보드 설정 열기를 누르세요.
  6. 핑거에러 켜기목록에서 핑거에러 스위치를 켜세요.

    "입력한 텍스트가 수집될 수 있어요"는 모든 키보드에 나오는 안드로이드 기본 경고예요. 핑거에러는 인터넷 권한이 아예 없어서 기록이 폰 밖으로 못 나가요.

  7. 키보드 바꾸기앱으로 돌아와 키보드 바꾸기 → 핑거에러를 고르세요.

    체험판을 쓰고 있었다면 지우지 말고 그 위에 그냥 설치하세요. 배운 기록이 그대로 이어지고 교정이 다시 켜져요.

아이폰

아이폰 IPA 받기FingerError.ipa · AltStore로 설치
아이폰은 앱스토어 밖 앱을 바로 못 깔아서 윈도우 PC와 AltStore가 필요해요. 처음 한 번만 PC로 준비하면 돼요.
  1. PC 준비 (윈도우)애플 홈페이지에서 받은 iTunes와 iCloud를 설치하세요.

    마이크로소프트 스토어 버전 말고 애플 홈페이지 버전이어야 해요.

  2. AltServer 설치altstore.io에서 AltServer (Windows)를 받아 설치하고 실행하세요. 작업 표시줄 오른쪽 아래에 마름모 아이콘이 생겨요.
  3. 아이폰 연결아이폰을 USB로 PC에 꽂고, 아이폰에 "이 컴퓨터를 신뢰하겠습니까?"가 뜨면 신뢰.
  4. AltStore 깔기마름모 아이콘 → Install AltStore → 내 아이폰을 고르고 Apple ID로 로그인하세요.
  5. 신뢰 · 개발자 모드아이폰 설정 → 일반 → VPN 및 기기 관리에서 내 Apple ID를 눌러 신뢰.

    설정 → 개인정보 보호 및 보안 → 개발자 모드를 켜고 재시동하세요.

  6. IPA 받기아이폰 사파리로 이 페이지를 열고 위 아이폰 IPA 받기를 누르세요. 파일 앱의 다운로드 폴더에 저장돼요.
  7. AltStore로 설치AltStore 앱 → My Apps → 왼쪽 위 + → 받은 FingerError.ipa를 고르세요. PC와 아이폰이 같은 와이파이에 있어야 해요.
  8. 키보드 켜기설정 → 일반 → 키보드 → 키보드 → 새로운 키보드 추가에서 핑거에러를 고르세요. 글 쓸 때 🌐 지구본을 꾹 눌러 핑거에러로 바꾸면 돼요.
  9. 7일마다 새로고침무료 Apple ID로 깐 앱은 7일 뒤 멈춰요. PC에서 AltServer를 켜 두고 같은 와이파이에서 AltStore → My Apps → Refresh All을 누르면 다시 7일 연장돼요.

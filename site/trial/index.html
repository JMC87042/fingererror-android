설치 순서

  1. 파일 받기위 초록 버튼을 누르세요. "파일을 다운로드할까요?"가 나오면 다운로드.
  2. 파일 열기다운로드가 끝나면 아래에 뜨는 열기를 누르세요.

    놓쳤다면 내 파일 → 다운로드에서 FingerError-trial.apk를 누르면 돼요.

  3. 출처 허용"보안상 이 출처의 앱을 설치할 수 없어요"가 나오면 설정 → 이 출처 허용을 켜고 뒤로 가세요.

    처음 한 번만 나와요. 크롬에서 받았으면 크롬, 내 파일에서 열었으면 내 파일을 허용하는 거예요.

  4. 설치설치를 누르세요.

    "Play 프로텍트" 창이 뜨면 자세히 → 무시하고 설치. 플레이스토어 밖에서 받은 앱이라 뜨는 기본 안내예요.

  5. 앱 열기핑거에러 앱을 열고 키보드 설정 열기를 누르세요.
  6. 핑거에러 켜기목록에서 핑거에러 스위치를 켜세요.

    "입력한 텍스트가 수집될 수 있어요"는 모든 키보드에 나오는 안드로이드 기본 경고예요. 핑거에러는 인터넷 권한이 아예 없어서 기록이 폰 밖으로 못 나가요. 확인을 누르세요.

  7. 키보드 바꾸기앱으로 돌아와 키보드 바꾸기 → 핑거에러를 고르세요.

    앱 아래 연습 칸에 바로 쳐 보세요. 앱 맨 아래 버전에 무료 체험판이 보이면 성공이에요.

무료 체험 14일

처음 설치한 날부터 14일 동안 모든 기능을 쓸 수 있어요. 남은 3일부터는 팻핑이가 하루 한 번 알려줘요.

14일이 지나면 자동 교정만 쉬어요. 타자, 오타 배우기, 리포트는 그대로 돼요. 배운 기록은 폰에 그대로 남아 있어요.

자주 묻는 것

"앱이 설치되지 않았습니다"가 떠요

예전에 받은 다른 핑거에러가 있으면 지우고 다시 설치해 보세요. 저장 공간이 부족해도 이 문구가 떠요.

키보드가 안 바뀌어요

글 쓰는 칸을 누른 뒤 화면 아래 키보드 모양 아이콘을 누르고 핑거에러를 고르세요. 아이콘이 없으면 앱의 '키보드 바꾸기' 버튼을 쓰세요.

14일이 지나면 어떻게 돼요?

자동 교정만 쉬고, 타자·오타 배우기·리포트는 그대로 돼요. 체험판을 지우면 배운 기록도 같이 지워지니 지우지 말고 두세요.

아이폰은요?

이 체험판은 갤럭시·안드로이드용이에요. 아이폰 버전은 따로 안내할게요.

내 글이 어디로 가나요?

아무 데도 안 가요. 인터넷 권한이 없는 앱이라 엄지 기록은 이 폰 안에만 저장돼요.

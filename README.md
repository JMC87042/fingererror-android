# 핑거에러 키보드 (안드로이드)

쓸수록 내 엄지에 맞춰지는 한글 두벌식 키보드. 학습 기록은 폰 안에만 저장되고 인터넷을 쓰지 않습니다.

## 빌드
1. GitHub에 빈 저장소 `fingererror-android` 만들기 (Public, README 없이)
2. 이 폴더의 `upload.bat` 더블클릭
3. Actions에서 초록 체크 확인

## 폰에 설치
1. 안드로이드 폰 브라우저로 열기:
   https://github.com/JMC87042/fingererror-android/releases/latest/download/FingerError.apk
2. "출처를 알 수 없는 앱 설치" 허용 → 설치
3. 핑거에러 앱 실행 → 키보드 설정 열기 → 핑거에러 켜기 → 키보드 바꾸기

새 버전도 같은 링크로 받아 덮어 설치하면 학습 기록이 그대로 유지됩니다.
